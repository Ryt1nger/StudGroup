# Вырезанные ассеты StudGroup (Stage 0)

Сделано автоматически из наборов в `../assets/`; оригиналы не менялись. Подробности по каждому файлу — в `manifest.json` (источник, область на листе, тема, статус, примечание).
Предпросмотр на светлом и тёмном фоне — в `_preview/`.

| Папка | Содержимое | Источник |
| --- | --- | --- |
| `brand/` | логотип (горизонтальный, с тэглайном и без), знак, wordmark, иконка приложения; light/dark | `B2`, `B1`, `Unknown-4` |
| `nav/` | иконки нижней навигации: home/tasks/schedule/subjects × active/inactive × light/dark (полный набор) | листы `A1`, `A3` |
| `nav/hires-partial/` | те же иконки в большем разрешении, но с неполным набором состояний | `B2`, `B1` |
| `utility/` | поиск, колокольчик (с точкой), шевроны, скрепка, внешняя ссылка, «⋯», аватар «A», точка уведомления | `B2`, `B1` |
| `files-status/` | значки файлов (PDF, документ, видео, изображение), ссылка, объявление, дедлайн, «изменение» | `B2`, `B1` |
| `subjects/` | иконки предметов (6) | `B2`, `B1` |
| `illustrations/` | пустые состояния, папки, маскот, баннеры, орбы, волны, карточки; light/dark | `B3`, `B4` |
| `backgrounds-lowres/` | миниатюры фонов из библиотечных листов | `B5`, `B6` |

## Ограничения (важно)

- **Всё — растр** (PNG, сгенерированные изображения). Для логотипа, иконок навигации и служебных иконок в продакшене нужен **SVG от дизайнера**; здесь — рабочие вырезки.
- **Статус `low-res`/`partial`/`deferred`/`needs-check` в `manifest.json`** показывает, что файлу нельзя доверять без проверки. `deferred` = связано с функциями, отложенными решением владельца (AI-маскот, «Спросить AI», предметы).
- `backgrounds-lowres/` — миниатюры (~200 px по длинной стороне), **не для продакшена**. Для реальных фонов нужны экспорты дизайнера.
- Иконки навигации получены преобразованием «цвет в альфу» с плиток листа и имеют глиф ≈ 50 px.
- Шрифт Inter в пакете отсутствует (по решению владельца подключаем локально, `@fontsource/inter`).
- Файлы не подключены ни к какому коду; окончательное расположение (`apps/frontend/...`) определится при scaffold.
