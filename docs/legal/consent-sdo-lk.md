# Отдельное добровольное согласие на обработку учётных данных СДО / ЛК

**Редакция 08.11.2026. ПРОЕКТ.**  
**Оператор:** [ОПЕРАТОР], [АДРЕС], [КОНТАКТ].

Я даю отдельное добровольное согласие на обработку **личного логина и пароля**, которые применяются для моей учётной записи в системе дистанционного обучения (СДО) и личном кабинете (ЛК) образовательной организации, а также адреса соответствующего портала.

**Цель:** сохранить данные в зашифрованном виде, чтобы по моему отдельному запросу в будущем подключать разрешённые функции учебных сервисов (расписание и ссылки занятий). **Сейчас сохранение не подтверждает авторизацию и не означает, что интеграция с порталом работает.**

**Действия:** приём через защищённую форму Mini App по HTTPS, шифрование на сервере, хранение и обновление, последующее использование только при наличии технического и законного основания, удаление по моему запросу или при отзыве согласия. Мой пароль не показывается в Telegram-переписке, не возвращается из API и не передаётся старосте или другим студентам.

Я понимаю, что передавать пароль третьему сервису необязательно. Я могу **не давать это согласие** и продолжить использовать основные функции StudGroup; я могу отозвать согласие и удалить реквизиты через настройки. Я подтверждаю, что ввожу собственные реквизиты, а не данные другого лица.

**Срок действия:** пока действует моя цель хранения либо до моего отзыва; пароль удаляется после отзыва, если нет отдельного законного основания для обработки. **Подрядчики, имеющие доступ:** [ПЕРЕЧЕНЬ, СТРАНЫ, ДОГОВОРЫ — ЗАПОЛНИТЬ]. **Контакт для отзыва:** [КОНТАКТ].

Это согласие не включает маркетинг, публикацию данных и автоматическую передачу пароля каким-либо внешним поставщикам AI. Любая реальная интеграция с СДО/ЛК требует проверки условий РАНХиГС и безопасности авторизации.
