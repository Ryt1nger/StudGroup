# StudGroup: комплект документов по персональным данным (черновик для согласования)

**Версия пакета: 2026-11-08 / draft 1. НЕ ПУБЛИКОВАТЬ от имени оператора до заполнения реквизитов и юридической проверки.**

Состав:
1. `privacy-policy.md` — политика обработки персональных данных, публичная, ст. 18.1 152-ФЗ.
2. `terms-of-use.md` — пользовательское соглашение, отдельно от согласий.
3. `consent-service.md` — отдельный документ согласия для тех целей, где выбран правовой базис «согласие».
4. `consent-sdo-lk.md` — отдельное, добровольное согласие на учётные данные СДО/ЛК.
5. `cookie-notice.md` — уведомление о локальных технических данных.
6. `internal-procedures.md` — внутренний регламент защиты, запросов, инцидентов и уничтожения.
7. `launch-checklist.md` — обязательные проверки и документы до production.

В СтудGroup **не должно быть «одной общей галочки на всё»**. Ознакомление с условиями (договор) и конкретные согласия — разные события. Все согласия оформляются отдельно; запрещены заранее отмеченные чекбоксы. Согласие на СДО/ЛК нельзя ставить условием доступа к основным функциям.

Поля **[ОПЕРАТОР]**, **[ЮРИДИЧЕСКИЙ АДРЕС]**, **[КОНТАКТ ДЛЯ ОБРАЩЕНИЙ]**, **[ИНН/ОГРН ПРИ НАЛИЧИИ]**, **[ПРОВАЙДЕР И РФ-ЛОКАЦИЯ БАЗЫ]**, **[ОТВЕТСТВЕННЫЙ]**, **[ПОЛИТИКА ХРАНЕНИЯ]**, **[ПЕРЕЧЕНЬ ПОДРЯДЧИКОВ]** нельзя заполнять догадками. До утверждения нет основания заявлять юридическое соответствие 152-ФЗ.

Источники: 152-ФЗ, ст. 6, 9, 12, 14, 18, 18.1, 19, 21–22; изменения 2025–2026. Тексты подлежат проверке юристом с учётом модели оператора, местоположения базы и вузовских правил использования СДО.
