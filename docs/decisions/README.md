# Architecture Decision Records

Use one Markdown file per significant technical decision.

Recommended format:

```text
# ADR-NNN: Decision title
Status: proposed | accepted | superseded
Date: YYYY-MM-DD

## Context
## Options
## Decision
## Consequences
```
