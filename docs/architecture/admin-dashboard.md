# Админский дашборд

Адрес страницы: `/admin/` на том же домене, что и backend API. В личном чате с ботом
слово «админ» (регистр не важен) показывает одну кнопку «Открыть админку», если задан
`ADMIN_PAGE_URL` (полный HTTPS-адрес этой страницы). Команда `/admin` сохраняет
прежний экран управления группами и также показывает кнопку дашборда. Telegram
открывает WebApp после нажатия кнопки пользователем. Страница работает как Telegram
WebApp: `initData`
проверяется существующим `/v1/session/bootstrap`, затем read-only запросы идут в
`GET /v1/admin/dashboard`. Токен хранится только в памяти вкладки. Доступ к данным
разрешён только `BOT_ADMIN_USER_ID`; членство в группе и роль старосты сами по себе
не дают доступа. Страница не выводит исходные сообщения, личные данные или ответы AI.

Данные запрашиваются при открытии, смене группы, ручном обновлении и раз в минуту,
пока вкладка видима. Каждая выборка выполняется по текущим строкам PostgreSQL; поле
`as_of` показывает время среза. При недоступности API старые значения остаются на
экране, а статус показывает ошибку.

| Блок | Источник и смысл |
| --- | --- |
| Группы и участники | `groups` с `status=active`, `pilot_authorized=true`; активные `memberships` |
| Поток сообщений | `raw_messages.message_date` за последние 7 дней, последнее сообщение и распределение по `processing_state` |
| Публикации | `homework.status=published`, действующие `academic_deadlines`, активные `canonical_academic_items`, опубликованные `group_events` |
| Уточнения | Действующие `academic_deadlines.needs_clarification=true` |
| Очереди | Состояния `ai_jobs`, `shadow_evaluation_runs`, `image_analysis_jobs`; `bot_outbox` общесистемный |
| Расходы | Отдельно суммы `analysis_budget_calls.charged_usd`, незакрытых резервов, `ai_attempts.charged_usd` и `image_analysis_calls.charged_usd`. Журналы могут описывать одни и те же вызовы, поэтому эти суммы нельзя складывать. |
| Режимы | Текущие runtime-флаги, `group_analysis_settings.analysis_mode` и `paid_outcome_hold` |
| Расписание | Текущая версия расписания каждой группы из `groups.schedule_version` |
| Инциденты | Открытые `owner_incident_episodes`, без деталей запросов и личного текста; блок общесистемный |

Фильтр группы применяется только к сущностям с `group_id`; инциденты и Telegram
outbox всегда общесистемные. Метрики имеют разные сроки хранения исходных строк;
нулевое значение означает отсутствие строк в текущей БД, а не доказательство
отсутствия исторической активности.

## Приёмка

- Обычный пользователь получает 403 на API; отсутствующий или истёкший токен — 401.
- Фильтр группы не включает строки другой группы; несуществующая группа — 404.
- Счётчики меняются после изменения строк БД без пересборки интерфейса.
- API и HTML не раскрывают текст сообщений и секреты.
- На слово «админ» кнопка появляется только при заданном `ADMIN_PAGE_URL` в личном
  чате пользователя `BOT_ADMIN_USER_ID`; другим пользователям ссылка не выдаётся.

Новый API аддитивен и не меняет контракты пользовательского фронтенда или его
существующие ответы. Контракт локален для страницы backend; несовместимых изменений нет.
