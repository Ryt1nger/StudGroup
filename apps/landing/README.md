# StudGroup landing

Маркетинговый лендинг StudGroup. Отдельный пакет (React 19 + Vite), **не входит в `pnpm-workspace.yaml`** и не связан с Telegram WebApp из `apps/frontend`. Зависимости ставятся через npm, чтобы не менять `pnpm-lock.yaml`.

## Запуск

```bash
cd apps/landing
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc + vite build -> dist/
npm run preview
```

## Структура

- `src/content.ts` — весь текст, цены, ссылки, отзывы, FAQ.
- `src/App.tsx` — секции страницы.
- `src/styles.css` — стили и токены (`:root`).
- `src/assets/*.webp` — нарезка из присланных листов; `src/assets/brand/` — логотипы из `design/extracted/brand`.

## Ссылки на бота

Все ссылки ведут на `https://t.me/studgroup_rf_bot?start=<тема>` (`botLink()` в `src/content.ts`). Telegram открывает бота и сразу выполняет команду; обработчик — `apps/backend/src/studgroup/bot_info.py`.

| Тема | Где на лендинге | Команда в боте |
| --- | --- | --- |
| `connect` | все «Подключить группу», «Подключение» в подвале | `/connect` |
| `tariffs` | «Тарифы» в подвале | `/tariffs` |
| `howto` | «Инструкция» в подвале | `/help` |
| `faq` | «Все вопросы», «Попробовать бесплатно», «FAQ» в подвале | `/faq` |
| `support` | «Обсудить», «Поддержка» в подвале | `/support` |

Username можно переопределить переменной `VITE_BOT_USERNAME` (Render → Environment) без изменения кода. Новая тема = строка в `PAYLOADS`/`COMMANDS` бота + значение `BotTopic` здесь.

## Анимации

CSS + немного React, без библиотек. Вход hero по очереди, плавающие 3D-иконки у телефонов (`float-*.webp` — из `design/extracted/illustrations`), параллакс от мыши (только `pointer: fine`), появление секций при скролле (`data-reveal` + IntersectionObserver), count-up для «200+», hover-эффекты, медленный дрейф фона, стеклянная шапка при скролле. При `prefers-reduced-motion: reduce` всё отключается, контент остаётся видимым.

`phones-dark.webp` — исходный макет с телефонами, из которого убран запечённый стеклянный «куб» (нижняя часть второго телефона плавно уходит в фон).
