# StudGroup landing (v2 «Маркер»)

Отдельный пакет Vite + React + TS (npm, не входит в pnpm-workspace). Render: статический сайт `studgroup-landing`, ветка `landing`.

```bash
cd apps/landing && npm ci && npm run dev   # сборка: npm run build
```

## Идея
Тёмный шумный чат группы → маркер выделяет важное → светлая страница с порядком. Главный момент — живой чат в hero (`Hero.tsx`): сообщения приходят, маркер отмечает задания и переносы, вопросы пропускаются, карточки «падают» в приложение. Поведение в демо и на странице повторяет правила из `docs/product/module-0-domain-rules.md` (не выдумывать, источник, ревизии, приоритет источников).

## Структура
- `content.ts` — весь текст и ссылки (бот: `botLink(topic)` → `https://t.me/studgroup_rf_bot?start=<topic>`; username переопределяется `VITE_BOT_USERNAME`)
- `Hero.tsx` живой чат · `Demo.tsx` проверка сообщений · `Day.tsx` сцена «один день» (sticky-телефон) · `Rest.tsx` правила, тарифы-пропуска, FAQ-диалог, CTA, футер
- шрифты: Unbounded (заголовки), Inter (текст). `prefers-reduced-motion` отключает анимации, чат показывается в финальном состоянии.
